# Светофор прогресса студентов

Преподаватель видит на странице группы, каким студентам нужна помощь, пока срок
сдачи ещё не истёк. Панель «Прогресс студентов» строится по открытым отчётам
опубликованных практик группы.

- API: `GET /api/v1/groups/{group_id}/student-risk` — только роль TEACHER и только
  для групп, которыми владеет преподаватель; чужая организация получает 403.
- Содержимое отчётов в ответ не попадает: только имя студента, статус, срок,
  процент заполненности и дни без правок.
- Правила: `backend/app/services/student_risk.py` (чистые функции без БД).

## Правила

«Написано» — доля разделов, доступных студенту для редактирования, в которых не
менее 20 слов. «Без правок» — дни с последнего изменения отчёта (время до начала
практики не считается). «Ожидаемо» — доля прошедшего срока практики.

| Уровень | Условие |
| --- | --- |
| Зелёный | отчёт уже сдан (SUBMITTED, UNDER_REVIEW, APPROVED, LOCKED), практика ещё не началась или нет признаков риска |
| Красный | срок прошёл, а отчёт не сдан (`OVERDUE`); либо до срока ≤ 3 дней и написано меньше 50% (`DEADLINE_SOON_LOW_PROGRESS`) |
| Жёлтый | нет правок ≥ 5 дней (`NO_RECENT_ACTIVITY`); либо написано меньше «ожидаемого» более чем на 25 п.п. (`BEHIND_SCHEDULE`) |

Даты считаются по UTC. Порог каждого правила — константа в `student_risk.py`.

## История написания

На странице отчёта преподаватель видит, как рос черновик: столбец на каждый день
с работой, текущее число слов, число дней и сохранений.

- Каждое успешное сохранение черновика записывает в `report_writing_snapshots`
  только счётчики: число слов в разделах, доступных студенту, прирост, число
  сохранений. **Текст отчёта не сохраняется и не возвращается.**
- Сохранения с паузой не больше 10 минут объединяются в одну запись, поэтому
  автосохранение не создаёт строку на каждое нажатие клавиши.
- `largest_save_words` — самый большой прирост за одно сохранение. Если он не
  меньше 300 слов, день подсвечивается и показывается нейтральная подсказка:
  это может быть вставка готового текста, стоит спросить студента. Это повод
  для разговора, а не доказательство плагиата.
- API: `GET /api/v1/reports/{report_id}/writing-history` — только преподаватель,
  которому принадлежит группа; показываются последние 180 дней (UTC).
- История начинается с момента обновления: прошлые сохранения не восстановить.

## Ограничения

- Уровень — подсказка для разговора со студентом, а не оценка работы.
- Светофор и история работают для отчётов редактора (`LEGACY_DOCUMENT_EDITOR_ENABLED`).
- Студентов стоит предупредить, что преподаватель видит динамику числа слов.
